# V Player (com.vplayer.app)

Kotlin + Jetpack Compose + AndroidX Media3 ExoPlayer.
Features: local video picker, direct URL playback, play/pause/seek/rewind/fast-forward, speed control,
favorites, watch history with resume.

Build: open this folder in Android Studio -> Build > Build APK(s)
or push to GitHub (public repo) and download the APK from the "Build APK" Actions run.
Output: app/build/outputs/apk/debug/app-debug.apk
